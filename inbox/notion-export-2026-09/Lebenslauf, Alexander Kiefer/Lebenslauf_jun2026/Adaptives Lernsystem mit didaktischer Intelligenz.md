# **2. Der entscheidende Unterschied zu bestehenden Lern-Apps**

Viele Apps machen entweder:

- 📚 statische Lerninhalte (simple Erklärungen)
- 🤖 ChatGPT als Tutor ohne Struktur
- 🎮 Gamification ohne echten Lehrplanbezug

**Dein Ansatz ist anders:**

Lehrplan → Lernziel → didaktische Sequenz → Interaktion → Feedback → Anpassung

Das ist didaktisch viel stärker.

# **3. Kernarchitektur deiner App**

Ich würde das so strukturieren:

**🧠 1. Curriculum Engine**

- Bundesland auswählen
- Klassenstufe
- Fach (Physik, Mathe, etc.)

→ strukturierter Lehrplan-Graph

**📖 2. Knowledge Layer**

- feste Inhalte (validiert)
- KI-ergänzte Erklärungen
- Beispiele / Analogien

👉 wichtig: KI nicht frei halluzinieren lassen

**🎓 3. Didaktik Engine (dein USP!)**

1. Aktivierung (Vorwissen)

2. Erarbeitung

3. Übung

4. Sicherung

5. Transfer

**🎮 4. Interaction Layer (Gamification)**

- kleine Simulationen
- Quiz-Mechaniken
- Mini-Experimente
- Story-Szenarien

**🧩 5. Adaptiver Lernpfad**

Schülermodell:

- Verständnislevel
- Fehlerhistorie
- Geschwindigkeit
- Frustration-Level

→ passt Inhalte dynamisch an

# **Projektziel**

Es soll ein vollständig lokales Multi-Agenten-Demonstrationssystem in Python entstehen.

Das System dient primär Lern- und Demonstrationszwecken.

Es soll die Funktionsweise moderner Multi-Agenten-Architekturen visuell und nachvollziehbar erklären.

Das System soll zunächst vollständig ohne KI-Modelle funktionieren.

Später sollen beliebige Modelle dynamisch angeschlossen werden können:

- GPT
- Claude
- Gemini
- Llama
- Mistral
- BERT
- lokale Modelle
- zukünftige Modelle

Die Architektur darf niemals von einem bestimmten Modell abhängig sein.

Modelle müssen über Adapter eingebunden werden.

# **Hauptziel**

Das System soll zeigen:

- wie Agenten arbeiten
- wie Agenten kommunizieren
- wie Agenten Aufgaben delegieren
- wie Agenten Informationen austauschen
- wie Agenten Entscheidungen treffen
- wie Agenten Fehler erkennen
- wie Agenten sich gegenseitig überwachen
- wie Agenten orchestriert werden

Das gesamte Verhalten soll in Zeitlupe beobachtbar sein.
